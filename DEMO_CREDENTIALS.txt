PitchSync Frontend Demonstration Access
=======================================

There are no predefined user accounts or real credentials.
Authentication services are not connected.

Sign-in URL:
http://localhost:3000/sign-in

Email:
Enter any email-shaped value.

Password:
Enter any non-empty value.

The password is validated only for being non-empty and is never stored.
Do not enter a real or sensitive password.

After continuing, select one of these demonstration roles:

- Super Administrator
- Cricket Board Administrator
- Team Performance Manager
- Match Official
- Integrity & Compliance Officer
- Player

The browser session stores only a temporary signed-in boolean and the
selected role under the sessionStorage key "pitchsync-demo-session".

Backend completion: 0%
Database integration: deferred
Real authentication: deferred
